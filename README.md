RFID-Based Cashless Payment System for School Canteens

Project Overview

The RFID-Based Cashless Payment System for School Canteens is a capstone project designed to provide a faster, safer, and more efficient way of handling payments inside the school canteen. The system uses RFID technology to identify students and process transactions automatically.

Students use RFID cards to purchase food and beverages without using cash. The system records every transaction in real time and updates the student’s wallet balance automatically. Parents can monitor their child’s transactions and balance through the web portal.


Objectives

General Objective

To develop an RFID-based cashless payment system that improves the efficiency, security, and convenience of canteen transactions.

Specific Objectives

- To implement RFID technology for student identification.
- To automate payment processing inside the school canteen.
- To provide real-time balance monitoring and transaction history.
- To reduce long queues and manual cash handling.
- To generate sales and transaction reports for administrators.

---

Features

Admin Module

- Manage students, parents, and staff accounts
- Manage RFID card registration
- Monitor transactions and balances
- Generate reports and sales summaries
- Manage food menu and prices

Staff Module

- Process orders and payments
- Recharge student RFID wallets
- View transaction records
- Manage cart and sales

Parent Module

- View student balance
- Monitor transaction history
- Receive notifications and updates

Student Module

- Tap RFID card for payment
- Automatic balance deduction
- Display remaining balance after transaction
